# Tutorial island (the Gods' Playground)

A separate small island, the Gods' Playground, where the Island Keeper walks the player through the controls in six
lessons: dragging and turning, tilting, all of them together, zooming, picking things up and double clicking. It is not
part of the story: the player goes there from the first land with F2, which the advisors suggest, and comes back with
Escape. The story's own teaching, in the opening of the first land, is in tutorial.md.

The original reaches it (checked 2026-10-31): F2 in a single-player story game (`GGame::ProcessKey` 0x63F0F5, not a
skirmish, not multiplayer, no help sequence on screen) opens the question box (0x54CB50); its yes (0x54C930)
quick-saves to slot 20, stops every script, loads `scripts\landT.txt` and starts `LandControlT`, which is in the
shipped `challenge.chl` (challenge 90). Both `Scripts/LandT.txt` and `Data/Landscape/LandT.lnd` ship with the game.
So these rows are the original's, not a cut feature. openblack's F2 and its yes are ported (2026-10-31); the way back
is not. The island's lessons are measured by
a quest run of `LandControlT` on `LandT.txt` (timeline `quest.tutorial_island`, spec
`tools/checks/story/quests/tutorial_island.txt`).

The game over cannot happen here, as the player has no temple: [losing_and_game_over.md](losing_and_game_over.md).
